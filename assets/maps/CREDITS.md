The file is unmodified. It is loaded at runtime by `src/meshmap.js`, which scales it from Half-Life units to meters (0.0254) and turns it right side up.
The same triangles drive rendering, player/bot collision, bullets and grenades.

de_dust2 itself is a Valve map: keep this build private (play with friends) and don't publish or sell it.
